Drop your local font files here. Required filenames:

  Vazirmatn-Regular.woff2          (Persian body)         ← you already have it
  Vazirmatn-Bold.woff2             (Persian display)      ← you already have it
  Inter-Regular.ttf                (Latin body)
  Inter-Medium.ttf                 (Latin body)
  CormorantGaramond-Medium.ttf     (Latin display)
  CormorantGaramond-Bold.ttf       (Latin display)

If any font is missing, the page falls back gracefully to system fonts.

Easiest source for the Latin TTFs:
  - Inter:               https://fonts.google.com/specimen/Inter             → "Download family" (.ttf inside)
  - Cormorant Garamond:  https://fonts.google.com/specimen/Cormorant+Garamond → "Download family" (.ttf inside)

Inside the downloaded zip, pick the matching weights:
  - Inter:  static/Inter-Regular.ttf, static/Inter-Medium.ttf
  - Cormorant: CormorantGaramond-Medium.ttf, CormorantGaramond-Bold.ttf
